A FEW USEFUL SHORTCUTS

Make room for discovery.

Place: drag any tool onto the grid. Or choose a line tool, click its start, then click its end.

Connected rays: each click adds a segment. Press Enter or double-click to finish; Escape cancels the unfinished segment. Orange junction handles move all connected segments together.

Grid size: choose large-grid rows and columns, then Apply grid size. Each large square contains 5 × 5 small squares. For example, 10 rows and 8 columns gives a portrait grid. Grid Scale refers to one small square.

Labels: drag an endpoint label, measurement, point name, or observer name independently. Select a label and press Delete to remove just its text. Re-enter text in its parent object’s Properties to restore it.

Edit: select a diagram element. Drag its endpoints to resize, or use the circular handle to rotate. The Properties panel provides precise controls, including label offsets.

Navigate: scroll to zoom around the pointer; Space + drag, middle-drag, or the Pan tool to move. Press 0 to fit the page.

Snap: grid snapping uses square intersections. Object snapping uses existing endpoints; rays automatically join other ray endpoints. Turn it off to place an independent endpoint.

Save: Save project downloads an editable .ray.json file. Open reloads it. The current diagram also autosaves in this browser.
